花草帳 — Expense Tracking LINE Bot

A conversational expense-tracking tool built to make everyday spending records quick to add and easy to review inside LINE.

PythonLINE BotngrokJavaScriptAPI Integration

01 — OVERVIEW

From a simple idea to a working conversation flow.

The project explores expense tracking through a familiar chat interface. The bot supports adding an expense with item, amount, and date information, reviewing saved records, checking the current total, and accessing help and date-related interactions.

02 — CORE FEATURES

Designed around everyday actions.

Add expenseRecord an item, amount, and date.
View recordsReview previously recorded expense items.
Check totalCalculate the current recorded spending total.
Date & help flowsTest date handling and guide the user through available commands.

03 — PRODUCT DEMO

04 — IMPLEMENTATION

Connecting conversational input with application logic.

The project presentation documents Python, LINE Bot, ngrok, and JavaScript as the technologies used. Expense information is structured as data and appended to an expense collection, with separate flows for adding data, viewing records, totals, dates, and help.

06 — DEBUGGING & LEARNING

Debugging became part of the project.

The project notes emphasize hands-on debugging during development. Rather than presenting debugging as a generic skill, this case study keeps it connected to a working project and its tested interaction flows.

07 — FUTURE IMPROVEMENTS

From records to spending insight.

Planned extensions include calendar reminders, daily checklist behavior, and weekly, monthly, or yearly spending charts delivered in the chat. These remain future improvements rather than completed features.
